B.Sc. thesis · Green University of Bangladesh

Memristor window functions and logic gates

Problem

Memristor models need window functions to keep the internal state within bounds, and different windows give different behaviour.

Approach

  • Compared window functions in a comparative study.
  • Designed logic gates in Memristor Ratioed Logic (MRL) using hybrid CMOS/memristor cells.

Result

A comparison of window functions and an XOR gate comparable to a CMOS implementation.
